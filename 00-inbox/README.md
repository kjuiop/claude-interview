# Inbox

> 빠른 캡처 공간. 나중에 분류할 fleeting notes를 여기 던진다.
> `/braindump` 스킬로 캡처, `/퇴근` 또는 `/weekly-review` 시 topics/ 로 이동.

---

## 사용 방법

- **바로 기록하고 싶을 때**: 이 폴더에 아무 파일이나 만들어도 됨
- **`/braindump` 명령**: 구술하면 자동으로 여기 파일로 저장
- **처리 규칙**: inbox 파일은 7일 이내 처리 (topics/ 이동 or 삭제)

## 파일 명명

`YYYYMMDDHHmm-{키워드}.md` 형식 권장
예: `202604011430-kafka-consumer-group.md`
