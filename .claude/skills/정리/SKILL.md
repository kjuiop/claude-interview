마크다운 파일의 **포매팅만** 교정한다. 내용(텍스트, 의미, 구조 판단)은 절대 건드리지 않는다.

## Step 1 — 대상 파일 확인

먼저 사용자에게 어떤 폴더 또는 파일을 정리할지 묻는다:

```
어떤 폴더/파일을 정리할까요?

예시:
- topics/kafka/          (폴더 전체)
- topics/kafka/concepts.md  (단일 파일)
- daily/                 (daily 폴더 전체)
```

사용자가 폴더를 지정하면 해당 폴더의 모든 `.md` 파일을 대상으로 한다.
하위 폴더 포함 여부는 사용자가 명시하지 않으면 **1단계 깊이만** 처리한다.

## Step 2 — 파일별 포매팅 교정

각 파일을 읽고 아래 규칙에 따라 교정한다. **파일 수가 많으면 병렬로 처리**한다.

### 교정 항목

**헤딩**
- `#` 뒤에 공백 1개 확인 (e.g., `##제목` → `## 제목`)
- 헤딩 앞뒤로 빈 줄 1개 (파일 첫 줄 제외)
- 헤딩 레벨 순서가 뛰는 경우(H1 → H3)는 **그대로 유지** — 의도적일 수 있으므로 내용 판단 없이 건드리지 않음

**리스트**
- 불릿 마커 통일: 같은 깊이에서 `-` / `*` / `+` 혼용 → `-` 로 통일
- 리스트 항목 앞 공백 정규화 (들여쓰기 2칸 기준)
- 리스트 블록 앞뒤 빈 줄 1개

**공백 및 빈 줄**
- 연속 빈 줄 2개 이상 → 1개로 줄임
- 파일 마지막에 빈 줄 1개 보장
- 줄 끝 trailing whitespace 제거

**코드 블록**
- 인라인 코드 백틱 쌍 확인 (홀수 백틱 방치 금지)
- 펜스 코드블록(```) 앞뒤 빈 줄 1개
- 언어 지정자 없는 코드 블록은 **그대로** — 언어를 추측해서 추가하지 않음

**테이블**
- 컬럼 구분자 `|` 앞뒤 공백 1개 정규화
- 헤더 구분선(`---`) 정렬 통일

**굵기/이탤릭**
- `**텍스트**` / `*텍스트*` 마커 바로 뒤 공백이 있는 경우 제거 (e.g., `** 텍스트 **` → `**텍스트**`)

**YAML frontmatter**
- `---` 구분선 앞뒤 포맷 확인
- frontmatter 내 들여쓰기/공백 정규화

### 절대 하지 않는 것

- 문장 내용 수정, 단어 교체, 문장 추가/삭제
- 헤딩 레벨 변경 (H2 → H3 등)
- 리스트 항목 순서 변경
- 코드 블록 내용 수정
- wikilink (`[[...]]`) 변경
- YAML frontmatter의 값 변경

## Step 3 — 결과 저장 및 보고

교정된 파일을 저장하고 아래 형식으로 결과를 출력한다:

```
## 정리 결과

### 처리한 파일 (N개)
- topics/kafka/concepts.md ✅ (trailing whitespace 12건, 빈 줄 정리 3건)
- topics/kafka/questions.md ✅ (불릿 마커 통일 5건)
- topics/kafka/examples.md ⏭ 변경 없음

### 변경 없음 (M개)
- ...
```

변경 내용이 없는 파일은 별도 목록으로 분리해 보여준다.
변경 건수가 0인 파일은 "변경 없음"으로 표시한다.
