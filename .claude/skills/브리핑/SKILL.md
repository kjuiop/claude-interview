---
name: 브리핑
description: 사용자로부터 메모를 입력받아 제텔카스텐 플리팅 노트(00-inbox/)를 생성한다. qmd MCP로 연관 노트를 검색해 기존 노트 기반 답변과 AI 보충을 함께 기록한다. 사용자가 `/브리핑` 또는 "브리핑", "메모 저장", "fleeting note"라고 하면 반드시 이 스킬을 사용한다.
---

사용자의 메모를 제텔카스텐 플리팅 노트로 저장한다.

## Step 1 — 메모 입력 받기

`/브리핑` 뒤에 메모가 있으면 그것을 사용한다.
없으면 "브리핑할 내용을 입력해주세요." 라고 묻는다.

## Step 2 — 제목 및 파일명 생성

메모의 핵심을 한 문장으로 요약해 제목과 파일명을 만든다.

- 제목: 15자 이내의 명사형 한 문장
- 파일명 형식: `00-inbox/YYYYMMDDHHmm-핵심키워드.md`
  - 공백은 `-`로 치환
  - 오늘 날짜와 현재 시각 사용 (`date +%Y%m%d%H%M` 으로 확인)

## Step 3 — 연관 노트 탐색 및 읽기

qmd MCP `query` tool이 있으면 그것으로, 없으면 Bash로 검색한다.

**MCP 방식:**
```
query(메모 핵심 키워드, collection="claude-interview")
```

**Bash 방식:**
```bash
qmd search "키워드" -c claude-interview --files --min-score 0.3
```

검색 결과에서 상위 3~5개를 선별한다.
선별한 노트를 모두 읽는다:

**MCP 방식:**
```
get("qmd://claude-interview/경로")
```

**Bash 방식:**
```bash
qmd get "qmd://claude-interview/경로"
```

읽은 내용을 바탕으로 메모/질문에 대한 답변을 내 노트 기반으로 작성한다.

## Step 4 — 노트 생성

아래 형식으로 파일을 생성한다.

```markdown
---
date: YYYY-MM-DD HH:mm
tags: [관련기술]
status: inbox
---

# {메모 핵심을 한 문장으로 요약한 제목}

---

## 📝 원문
{사용자가 입력한 메모를 오타·비문만 수정해 그대로 옮긴다. 내용 추가·삭제 없이}

---

## 🔍 내 노트 기반 답변
{연관 노트에서 읽은 내용을 종합해 사용자의 메모/질문에 직접 답변한다.
외부 지식이 아닌, 이미 기록해둔 노트의 언어와 맥락으로 답한다.
인용한 노트가 어느 내용에서 왔는지 흐름 안에서 자연스럽게 녹인다.}

---

## 💡 AI 생성
{내 노트에 없는 내용 중 보충하거나 심화할 것만 추가한다. 노트 기반 답변과 겹치지 않게}

---

## 🔗 연관된 노트
{qmd로 찾은 연관 노트를 마크다운 리스트로 작성한다.}
- [[topics/기술/파일명]] — 연관 맥락 한 줄 설명

---
처리 기한: {오늘로부터 7일 후}
이동 후보: topics/{기술명}/
```

## Step 5 — Obsidian으로 열기

노트 생성 후 Obsidian에서 해당 파일을 연다.

```bash
open "obsidian://open?vault=claude-interview&file=00-inbox/파일명.md"
```

파일명은 URL 인코딩한다 (공백 → `%20`).

## Step 6 — 완료 안내

파일 경로와 제목을 한 줄로 알린다.
예: `` `00-inbox/202606011430-kafka-replication.md` 생성 완료 — "Kafka 복제 팩터" ``
