### 로컬 개발 환경 구성 — Docker Compose

Confluent Kafka 7.1.x 기반 3-tier 로컬 환경.

```yaml
version: '3.8'

services:
  zookeeper:
    image: confluentinc/cp-zookeeper:7.1.10
    hostname: zookeeper
    container_name: zookeeper
    ports:
      - "2181:2181"
    environment:
      ZOOKEEPER_CLIENT_PORT: 2181
      ZOOKEEPER_TICK_TIME: 2000

  broker:
    image: confluentinc/cp-kafka:7.1.10
    hostname: broker
    container_name: broker
    depends_on:
      - zookeeper
    ports:
      - "9092:9092"
      - "29092:29092"
    environment:
      KAFKA_BROKER_ID: 1
      KAFKA_ZOOKEEPER_CONNECT: zookeeper:2181
      KAFKA_LISTENER_SECURITY_PROTOCOL_MAP: PLAINTEXT:PLAINTEXT,PLAINTEXT_HOST:PLAINTEXT
      KAFKA_ADVERTISED_LISTENERS: PLAINTEXT://broker:29092,PLAINTEXT_HOST://localhost:9092
      KAFKA_OFFSETS_TOPIC_REPLICATION_FACTOR: 1
      KAFKA_GROUP_INITIAL_REBALANCE_DELAY_MS: 0
      KAFKA_TRANSACTION_STATE_LOG_MIN_ISR: 1
      KAFKA_TRANSACTION_STATE_LOG_REPLICATION_FACTOR: 1

  schema-registry:
    image: confluentinc/cp-schema-registry:7.1.10
    hostname: schema-registry
    container_name: schema-registry
    depends_on:
      - broker
    ports:
      - "8081:8081"
    environment:
      SCHEMA_REGISTRY_HOST_NAME: schema-registry
      SCHEMA_REGISTRY_KAFKASTORE_BOOTSTRAP_SERVERS: broker:29092
      SCHEMA_REGISTRY_LISTENERS: http://0.0.0.0:8081
```

### 구성 요소

**ZooKeeper (포트 2181)**

- Kafka 브로커의 메타데이터 관리자 — 브로커 상태, 리더 선출, 토픽 설정 저장
- `ZOOKEEPER_TICK_TIME: 2000` — heartbeat 간격 2초, 세션 타임아웃 계산 기준
- Kafka 3.x KRaft 모드에서는 ZooKeeper 없이 동작 가능하지만, 7.1.x (= Kafka 3.1.x)은 아직 ZooKeeper 사용

**Broker (포트 9092 / 29092)**

리스너를 2개로 분리하는 것이 핵심:

| 리스너 | 주소 | 용도 |
|---|---|---|
| `PLAINTEXT` | `broker:29092` | Docker 내부 컨테이너 간 통신 |
| `PLAINTEXT_HOST` | `localhost:9092` | 호스트(맥)에서 접근할 때 |

- `KAFKA_OFFSETS_TOPIC_REPLICATION_FACTOR: 1` — 브로커 1개 환경이라 replication 1 (운영은 보통 3)
- `KAFKA_GROUP_INITIAL_REBALANCE_DELAY_MS: 0` — 컨슈머 그룹 리밸런싱 대기 없이 즉시 시작 (개발 편의)

**Schema Registry (포트 8081)**

- Avro / Protobuf / JSON Schema 버전 중앙 관리
- `SCHEMA_REGISTRY_KAFKASTORE_BOOTSTRAP_SERVERS: broker:29092` — 내부 네트워크로 브로커 연결
- 클라이언트는 `http://localhost:8081` 로 스키마 등록/조회

### 통신 흐름

```
[호스트 Producer/Consumer]
        │ localhost:9092
        ▼
    [broker]  ←── broker:29092 ──  [schema-registry]
        │
    [zookeeper:2181]
```
