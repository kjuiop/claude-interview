### 카프카 소개, 그리고 왜 카프카를 배워야 하는가?

- 카프카는 분산 시스템이다. 이벤트 시스템 플랫폼 (과거의 메시징 시스템)
- 대용량 처리, 트랜잭션 관리
- 데이터 스트림 (데이터가 끊임없이 들어오는 것을 분산시스템으로 처리)
- 고성능, 안정성
- 기업 데이터 저장소의 통합 구축 기반 제공하며 고성능 데이터 파이프라인 구축의 핵심 역할을 수행

### 환경 version

- Confluent Kafka 7.1.X (Apache Kafka 3.1.X 와 호환) 설치
- 서버 Java 는 JDK 11
- 클라이언트 Java 는 JDK 17
